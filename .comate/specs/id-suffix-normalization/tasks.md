- [x] Task 1: 在数据加载链路引入业务ID规范化与原始ID保留

    - 1.2: 在 `load_data()` 中为每条记录保留 `__raw_id`（原始唯一ID）
    - 1.3: 在 `load_data()` 中将展示/业务分组字段 `id` 规范化为去后缀值
    - 1.4: 确保无 `id` 场景、空值场景保持兼容

- [x] Task 2: 将 testcases 页面关键操作从 `id` 定位切换到 `__raw_id`/`__row_key`

    - 2.3: 保证页面展示仍使用规范化后的 `id`
    - 2.4: 保持现有批量操作、筛选、分页功能不回归

- [x] Task 3: 确保执行引擎按规范化后的业务ID进行 session 分组

    - 3.2: 确认同一 session（如 `GEN_001_T1/T2/T11`）被聚合为同一 `GEN_001`

- [x] Task 4: 回归验证与修复总结

    - 4.2: lints 检查并清理明显问题
    - 4.3: 验证示例 ID 规则：`TC012345_T1 -> TC012345`、`GEN_001_T11 -> GEN_001`
